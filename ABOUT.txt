JA LAN Messenger - Lightweight P2P Office LAN Messenger
================================================================================
Version: 1.8.1+18
Developer: JA Team
Language: Dart / Flutter Desktop
Architecture: Pure Dart P2P Sockets (UDP Broadcast/Multicast + TCP Streaming)
Protocol: Dual-Mode (BeeBEEP Compatible + JA Modern Packet)
Features:
- Scheduler Frame Gating & Zero Inactive GPU: PowerFrameGate overrides WidgetsBinding framesEnabled when inactive, blurred or minimized to eliminate rogue timer/setState repaints, and replays dirty UI seamlessly upon return
- Native Window Snapshot Reconcile & Remote Session Guard: Verifies genuine Win32 window focus and visibility to recover from missed RDP/VNC remote reconnect events without re-arming idle sleep
- Close-to-Tray Hardening & Atomic Preferences Durability: Prevents duplicated close prompts, displays close dialog without frozen transparent transitions, and serializes user settings via atomic flush/rename (.tmp)
- OTA Staging Auto-Cleanup: Safely purges temporary update ZIPs and staging folders upon verified launch of new version while preserving backup snapshots and rollback logs
- Flutter Desktop Power & GPU Optimizer: Single-source AppPowerManager managing 4 window states (Focus, Blur, Minimized, Idle Sleep 12s/30s/60s), 3 tiered ValueNotifiers, MeshOrb animation resume direction preservation, BounceMarquee freeze scroll offset & session epoch, native Win32 WM_ACTIVATE handling, and user power optimization settings UI
- Consistent Windows Branding & Metadata: Native window title bar, Taskbar tooltip, Task Manager and executable metadata display 'JA LAN Messenger' (by JA Tech) consistently across Windows 10 & 11 instead of the raw process binary name ('ja_lan_messenger.exe')
- Resilient AI Connection Recovery & Locator: Automatic discovery, ping tracking and background reconnection for Ollama/JA-AI engines
- Bento Smart File Inspector & Backdrop Dismissal: Multi-tab inspection for binary, office and archive files, pure Dart ZIP & Excel sheet parser, SHA-256 integrity checksum, hex dump viewer, copy physical file to clipboard, and tap-outside backdrop dismissal
- Smart 2-Octet Manual IP Suggestion & New Friend Badge: Auto-extracts active 2-octet network prefix with quick suggestion chips, connects with real-time feedback, and prioritizes newly added peers to top of contact list with an emerald 'Bạn mới' badge
- Smart Conversation Scroll Restoration: Preserves exact chat scroll offset and bottom intent across app restarts (conversation_scroll.json)
- Visible-Message Read Receipts: Real-time viewport dwell detection marks messages as read only when physically viewed on screen
- Persistent Taskbar Flashing & Tray Badge: Alternates icon badge and flashes Windows taskbar via native FlashWindowEx until unread messages are viewed
- Animated Sprite Stickers: Zalo-style sticker packs with tuned 18 FPS animations, auto-folder detection, hover previews & click-outside dismissal
- Packaging Auto-Cleanup: Automatically purges temporary staging folders (.package-stage-*, dist.previous-*) to save disk space and stop OneDrive clutter
- Copy Chat Images to Clipboard: 1-click image copy directly into Windows clipboard from message bubble
- Multilingual Network IP Sweep: Full real-time scanning progress localization across Tiếng Việt, English, 简体中文
- Decentralized serverless P2P communication on local area networks (LAN)
- Automatic peer discovery via UDP Broadcast (255.255.255.255:36475) & Multicast (224.0.64.75)
- Direct instant messaging over TCP port 6475
- High-speed binary chunked file transfer over TCP port 6476
- System Tray Toggle: 1-click on system tray icon toggles hide/restore window
- Responsive Chat Header: Auto-collapsing header with nickname marquee when Conversation Info is open
- Smart Chat Bubble Entity Detection: Auto-detects URLs, Phone numbers, Emails, and UNC/Windows paths with Bento Glassmorphic Quick Action Chips
- Selectable Chat Text: Full markdown text selection and copy with 1-click quick utilities
- Remote WinRM App Launch: Automatic remote app launch via WinRM on Buzz when peer is offline
- AES-256 encrypted credential protection with per-peer WinRM configuration
- Dynamic AI Assistant (JA-AI / Ollama) with live model detection, capability heuristics & auto-switch
- Message quoting & multi-message top pinning with jump-to-message navigation
- Compact, lightweight, responsive UI with Bento Glassmorphism styling & live glass tuning
- Native Windows 10 (Aero Blur) & Windows 11 (Mica/Acrylic) frame integration
- Safe atomic chat history persistence with offline message recovery & storage stats
- Multi-adapter selection and full-subnet active sweep
- Trilingual support: Tiếng Việt, English, 简体中文
- Ultra-low memory footprint (~40-60 MB RAM)
